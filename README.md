# すみだAIきょうしつ（AIプロジェクトチーム）

東京都墨田区の、**シニア（高齢者）向けAI教室**の立ち上げ企画一式です。
運営ブランドは **AIプロジェクトチーム**。

## 内容

| ファイル | 説明 |
|----------|------|
| `index.html` | 教室のWebサイト（1ページ・シニアにやさしい大きな文字／高コントラスト設計） |
| `docs/company-profile.md` | 会社概要・ブランドガイド（理念・バリュー・カラー・タイポ・ロゴ案） |
| `docs/business-plan.md` | 事業計画書（ターゲット・コース料金・立地・集客・収支概算・ロードマップ） |

## サイトの見方

`index.html` をブラウザで開くだけで表示できます（外部依存はGoogle Fontsのみ）。

- **対象**: 主に65歳以上のシニア（墨田区および近隣）
- **特徴**: 少人数・伴走型／専門用語なし／詐欺・偽情報の安心講座つき
- **ページ構成**: 教室のとくちょう ／ コース・料金 ／ みんなの声 ／ アクセス・お問い合わせ

住所・電話番号・メール・料金などは、すべて**仮（プレースホルダー）**です。
