# LINE公式アカウントの開設とサイト連携手順

シニアとそのご家族にとって、LINEは最も身近な連絡手段です。
LINE公式アカウント（無料プランあり）を開設し、サイトに「友だち追加ボタン」を表示しましょう。

---

## 手順1: LINE公式アカウントを開設する（無料・約15分）

1. https://entry.line.biz/start/jp/ にアクセス
2. 「LINE公式アカウントをはじめる」→ 個人のLINEアカウントまたはメールで登録
3. アカウント情報を入力:
   - アカウント名: `すみだAI教室`
   - 業種: 教育・習い事
4. 開設後、**LINE Official Account Manager**（管理画面）にログインできます

**無料プラン（コミュニケーションプラン）** で月200通まで送信可能。開始時はこれで十分です。

## 手順2: 友だち追加URLを取得する

1. 管理画面 → 「友だちを増やす」→「友だち追加ガイド」
2. **「URLを作成」** で `https://lin.ee/○○○○` 形式のURLをコピー
3. 同じ場所で **QRコード** もダウンロードできます（チラシ・名刺用に保存推奨）

## 手順3: assets/config.js に貼り付ける

```js
LINE_URL: "https://lin.ee/○○○○"
```

保存してmainにpushすれば、お問い合わせページに緑の「LINEで友だち追加・相談する」ボタンが自動で表示されます。

## おすすめ初期設定（管理画面でできること）

| 設定 | 内容 |
|------|------|
| あいさつメッセージ | 友だち追加時に自動返信。例:「友だち追加ありがとうございます。すみだAI教室です。ご質問はこのままメッセージでどうぞ。お電話（080-4885-5430）でも承ります」 |
| 応答メッセージ | 営業時間外の自動返信を設定 |
| プロフィール | ロゴ画像・受付時間・サイトURLを掲載 |
| リッチメニュー | トーク画面下部に「体験申込」「コース案内」「よくある質問」ボタンを配置（サイトの各ページへリンク） |

## 運用のコツ（シニア×家族向け）

- **家族が親のスマホで友だち追加してあげる**導線が実際は最多。チラシにQRコードを大きく載せる
- 月1〜2回の配信で十分（例: 講座日程、AIの豆知識、詐欺注意情報）
- 詐欺注意の情報配信は喜ばれやすく、ブロックされにくい鉄板コンテンツ
