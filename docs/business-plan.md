# 事業計画書 ─ すみだAI教室（AIプロジェクトチーム）

> ※ 数値は事業構想のための**概算モデル**です。実際の物件費・人件費・受講需要に合わせて必ず見直してください。

---

## 1. 事業概要

| 項目 | 内容 |
|------|------|
| 事業名 | すみだAI教室（運営: AIプロジェクトチーム） |
| 事業内容 | 高齢者向けのスマホ・AI活用教室（**オンライン＋出張**・少人数） |
| ターゲット | 主に65歳以上のシニア（オンライン: 全国／出張: 墨田区・近隣）＋その家族（子・孫世代） |
| 拠点 | 東京都墨田区（店舗を持たない身軽な運営） |
| 開業形態 | **無店舗型**（オンライン講座＋出張講座）。初期投資・固定費を最小化 |

---

## 2. 背景・課題（なぜ今、シニア向けAI教室か）

- 高齢者のスマホ保有は進んだが、「電話・LINE止まり」で**活用できていない**層が多い。
- 生成AIは急速に普及する一方、シニアは**取り残されやすく**、詐欺・偽情報の被害リスクも高い。
- 墨田区は**下町の高齢者コミュニティ**が根強く、「顔の見える・通える」対面教室と相性が良い。
- 既存のPC教室は多いが、**「AI × シニア専門 × 超やさしい」**に特化した教室は少ない。

---

## 3. ターゲットと提供価値

### メインターゲット
- 65〜80代。スマホは持っているが不安。新しいことに前向きな層。
- 家族（子・孫）が「親にAIを安全に使ってほしい」と考える層。

### 提供価値
1. **こわくない**: 用語を使わず、ゆっくり、何度でも。
2. **役に立つ**: 写真・手紙・翻訳・調べもの・健康情報など生活に直結。
3. **守れる**: 詐欺・偽情報の見分け方をセットで学べる。
4. **つながる**: 通うこと自体が仲間づくり・居場所になる。

## 5. 提供体制（無店舗型：オンライン＋出張）

- **店舗を持たない**ことで家賃・内装の固定費をゼロにし、価格と講師品質へ投資する。
- **オンライン**: Zoom等のビデオ通話。初回接続は電話で伴走（前日までに練習）。録画共有で復習可。全国が商圏。
- **出張**: 墨田区・近隣（江東・台東・葛飾・江戸川など）のご自宅・町会集会所・シニアクラブ・介護施設へ。貸出タブレット持参。
- 町会・地域包括支援センター・シニアクラブなど地域と連携し**紹介経路**を作る（墨田の下町コミュニティが起点）。

## 7. 収支計画（概算モデル・月次）

**前提（保守的な立ち上げ期の例）**
- 月額継続 30名 × 5,500円 = 165,000円
- 入門・単発講座 40名分 × 平均2,500円 = 100,000円
- 個別・出張 = 60,000円
- **月間売上（目安）: 約 325,000円 →** 生徒増で拡大

**主なコスト（目安・無店舗型）**
| 項目 | 月額（案） |
|------|------|
| 講師人件費 | 100,000円 |
| 通信・ツール・機材（貸出タブレット等） | 25,000円 |
| 交通費（出張） | 15,000円 |
| 販促・チラシ・Web | 20,000円 |
| その他運営費 | 15,000円 |
| **合計** | **約 175,000円** |

> 無店舗型のため家賃ゼロ。教室型（約28万円/月）に比べ損益分岐点が大幅に低く、小さく始めて生徒数と出張講座で伸ばすモデル。初期投資（機材・登記等）は別途。

## 8. ロードマップ

1. **0〜1ヶ月**: ブランド確定・サイト公開（SEO開始）・オンライン運用の型づくり・体験会告知
2. **1〜3ヶ月**: ワンコイン体験会（オンライン＋出張）・町会/シニアクラブとの連携づくり
3. **3〜6ヶ月**: 定期コース開講・月額会員獲得・家族経由（ギフト受講）の獲得強化
4. **6〜12ヶ月**: 出張講座（施設・自治体）を拡大・講師増員・オンライン枠の拡大

## 9. リスクと対策

| リスク | 対策 |
|--------|------|
| 集客が想定より遅い | 体験会・地域連携・家族経由を厚くする |
| 講師の確保 | マニュアル化・伴走型で講師の属人性を下げる |
| シニアのIT不安 | 「安心講座」で信頼を先に獲得 |
| 物件コスト | 公共施設・空きスペースの間借りから始める選択肢 |
