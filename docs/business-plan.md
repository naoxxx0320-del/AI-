| 項目 | 内容 |
|------|------|
| 事業名 | すみだAIきょうしつ（運営: AIプロジェクトチーム） |
| 事業内容 | 高齢者向けのスマホ・AI活用教室（対面・少人数） |

---

## 2. 背景・課題（なぜ今、シニア向けAI教室か）

- 高齢者のスマホ保有は進んだが、「電話・LINE止まり」で**活用できていない**層が多い。
- 生成AIは急速に普及する一方、シニアは**取り残されやすく**、詐欺・偽情報の被害リスクも高い。
- 墨田区は**下町の高齢者コミュニティ**が根強く、「顔の見える・通える」対面教室と相性が良い。
- 既存のPC教室は多いが、**「AI × シニア専門 × 超やさしい」**に特化した教室は少ない。

---

## 3. ターゲットと提供価値

### メインターゲット
- 65〜80代。スマホは持っているが不安。新しいことに前向きな層。
- 家族（子・孫）が「親にAIを安全に使ってほしい」と考える層。

### 提供価値
1. **こわくない**: 用語を使わず、ゆっくり、何度でも。
2. **役に立つ**: 写真・手紙・翻訳・調べもの・健康情報など生活に直結。
3. **守れる**: 詐欺・偽情報の見分け方をセットで学べる。
4. **つながる**: 通うこと自体が仲間づくり・居場所になる。

## 5. 立地戦略（墨田区）

- **通いやすさ最優先**: 主要駅（例: 錦糸町・押上・曳舟・両国 等）から徒歩圏、バリアフリー。
- 1階または EV ありの物件。段差・急な階段を避ける。
- 町会・地域包括支援センター・シニアクラブ・図書館などと連携し**紹介経路**を作る。
- スカイツリー周辺の「墨田＝新しいものと下町が共存する街」イメージも活用。

## 7. 収支計画（概算モデル・月次）

**前提（保守的な立ち上げ期の例）**
- 月額継続 30名 × 5,500円 = 165,000円
- 入門・単発講座 40名分 × 平均2,500円 = 100,000円
- 個別・出張 = 60,000円
- **月間売上（目安）: 約 325,000円 →** 生徒増で拡大

**主なコスト（目安）**
| 項目 | 月額（案） |
|------|------|
| 物件家賃 | 120,000円 |
| 講師人件費 | 100,000円 |
| 通信・機材（タブレット等） | 20,000円 |
| 販促・チラシ | 20,000円 |
| その他運営費 | 20,000円 |
| **合計** | **約 280,000円** |

> 立ち上げ期は小さく始め、生徒数の増加と出張講座で黒字化を目指すモデル。初期投資（内装・機材・登記等）は別途。

## 8. ロードマップ

1. **0〜1ヶ月**: ブランド確定・サイト公開・物件選定・体験会告知
2. **1〜3ヶ月**: 物件契約・無料/ワンコイン体験会・地域連携づくり
3. **3〜6ヶ月**: 定期コース開講・月額会員獲得・口コミ拡大
4. **6〜12ヶ月**: 出張講座を拡大・2教室目/曜日拡大を検討

---

## 9. リスクと対策

| リスク | 対策 |
|--------|------|
| 集客が想定より遅い | 体験会・地域連携・家族経由を厚くする |
| 講師の確保 | マニュアル化・伴走型で講師の属人性を下げる |
| シニアのIT不安 | 「安心講座」で信頼を先に獲得 |
| 物件コスト | 公共施設・空きスペースの間借りから始める選択肢 |
