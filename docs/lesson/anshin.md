# デジタル安心講座（90分）── 講師用

> 2,000円／90分／オンライン・出張／人数の制限なし
> **町会・シニアクラブへの主力商品**です。「AIを教える」より通りやすい看板になります。

---

## 1. 設計

### 到達目標
怪しい連絡が来たとき、**その場で反応せず、いったん止まれる**ようになること。

知識を増やすことが目的ではありません。**行動を1つ変える**のが目的です。

### 最低ライン
**「あわてて電話しない・リンクを押さない・その場で決めない」の3つ**が言えるようになる。

### この講座の性格
- 参加者は「教わりに来た」より「不安だから来た」人が多い
- 実物を見せる時間がいちばん効く。座学を短く、実物とクイズを長く
- **恐怖で煽らない。** 怖がらせると、かえってスマホを使わなくなります
- 最後に「持ち帰れる約束」を1つ作る

### 人数別の調整

| 人数 | 進め方 |
|------|--------|
| 1〜4名 | 各自のスマホで実際に確認まで行う |
| 5〜15名 | 講師の画面を投影。クイズは挙手 |
| 16名以上 | 投影＋声出し。個別対応はあきらめ、質問は最後にまとめる |

## 2. 事前準備

### 主催者（町会・施設）に確認すること
- 人数、平均年齢、車椅子の方の有無
- プロジェクターまたは大型テレビの有無（**なければ紙の拡大資料で代替**）
- 会場のコンセント、電源の位置
- 開始前に何分入れるか（設営に20分ほしい）

### 講師の持ち物
- 実物の詐欺SMS・詐欺ハガキの**印刷物**（A3に拡大したもの5枚）
- 貸出タブレット（スマホをお持ちでない方用）
- モバイル通信（会場Wi-Fiに頼らない）
- お持ち帰りカード（人数分＋予備10枚）
- Google口コミ用QRカード

### 実物の集め方
自分に届いたものを保存しておく。**受講者から提供してもらったものは、個人情報を必ず消してから使う。**

## 4. ブロックごとの進め方

### 0–10分：つかみ

自己紹介より先に、いきなり実物を見せます。

> 「まず、これを見てください。（A3に拡大した詐欺SMSを掲げる）
> **これ、本物だと思う方、手を挙げてください。**」

半分くらい手が挙がります。そこで：

> 「実はこれ、偽物です。ですが、いま手を挙げた方が悪いわけではありません。**見分けがつかないように作ってあるんです。**
> 今日は、どこを見れば分かるかを一緒に覚えて帰りましょう」

**「引っかかるのはあなたのせいではない」**を最初に置くのが肝心です。恥ずかしさを取り除かないと、以降の質問が出ません。

### 10–30分：見分け方 5つ

1つにつき4分。実物を見せながら。

| # | 見るところ | 説明 |
|---|-----------|------|
| 1 | **あせらせているか** | 「本日中に」「利用停止」。急がせるのは、考える時間を与えないため |
| 2 | **リンクを押させようとしているか** | 本物の会社は、SMSで支払い画面に直接誘導しません |
| 3 | **差出人** | 見慣れない番号、意味のない英数字の並び |
| 4 | **URLの文字** | 本物に似せた綴り。`.com` の前を見る |
| 5 | **日本語のわずかな不自然さ** | 句読点の位置、敬語のずれ。ただし最近は自然なものも増えています |

**5番については正直に言ってください。**

> 「昔は日本語が変で分かったのですが、いまはAIで自然な日本語が作れてしまいます。**日本語だけで判断するのは、もう危険です。**」

### 30–45分：実物クイズ 5問

1問3分。挙手 → 答え合わせ → どこが決め手か。

出題の順番：
1. 明らかな偽物（自信をつけてもらう）
2. 本物（宅配便の正規通知）← ここで「全部偽物だと思う」を崩す
3. 巧妙な偽物
4. 本物（自治体からの案内）
5. 極めて巧妙な偽物 ← 全員が間違えてよい

5問目で全員が外すのが理想です。

> 「これは私も、一瞬迷いました。**プロでも見分けられないものがあるんです。**
> だからこそ、次にお話しすることが大事になります」

### 45–55分：休憩

**必ず取ってください。** 90分続けるとシニアの集中は持ちません。
お手洗いの場所を必ず案内する。この時間に個別の質問が集まります。

### 55–70分：AIに確認させる実演

ここで初めてAIが出てきます。

1. 講師のスマホでChatGPTを開く（投影）
2. 怪しいSMSの**写真を撮って**見せる
3. 話しかける：「このメッセージが届きました。**本物かどうか、一緒に考えてください**」
4. 返ってきた内容を読み上げる

> 「大事なのは、AIが正解を出すことではありません。
> **写真を撮って、聞いて、答えを読む。この20秒のあいだに、あわてる気持ちが落ち着く。** これがいちばんの効果です」

「押す前のひと呼吸」という言い方を、この講座のキーワードにしてください。

### 70–80分：AIも間違える

> 「ただし、正直にお伝えしておきます。**AIも間違えます。**」

わざと間違えさせる実演を1つ。

> 「AIが『大丈夫です』と言っても、**それを理由に安心しないでください。**
> 迷ったら、必ず人に相談を。ご家族、それから **警察相談専用電話の #9110**。詐欺かもしれないと思ったら、こちらへどうぞ」

「うちの教室はAIを売りたいのに、AIを信じるなと言う」——この矛盾を自分から言うのが、いちばん信用されます。

### 80–88分：家族との約束を1つ決める

**この講座でいちばん価値があるのはここです。** 知識より、この約束が人を守ります。

> 「最後に、一つだけ決めて帰っていただきます。
> **お金の話が出てきたら、必ず先に相談する人を、一人決めてください。**
> 息子さん、娘さん、ご近所の方、誰でも構いません。そのお名前と電話番号を、いま配るカードに書いてください」

書く時間を3分取る。書いたら：

> 「そのカードを、**電話のそばに置いてください。**
> 相手が『誰にも言うな』と言ったら、それは100%詐欺です。本物の役所も銀行も、そんなことは言いません」

### 88–90分：締め

- お持ち帰りカードを全員に配る（書いた人はそのまま持ち帰り）
- 教室の案内は**チラシを置くだけ**。口頭で勧めない
- 口コミのお願いは、主催者にだけ

> 「本日はありがとうございました。**その場で入会をお願いすることは一切ありません。**
> 何かあったら、いつでもお電話ください」

## 5. つまずきポイントと対処

| 症状 | 対処 |
|------|------|
| 「自分は大丈夫」と言う人がいる | 否定しない。「そう思っていた方がいちばん狙われます」と5問目のクイズで体験してもらう |
| すでに被害に遭った方がいる | **その場で深追いしない。** 休憩時間に個別に。#9110 と消費生活センターを案内する |
| 話が脱線して個人の相談が始まる | 「あとで個別にうかがいます」と切り、休憩時間に回す |
| 会場に投影設備がない | A3印刷で代替。事前に確認しておく |
| スマホを持っていない方 | 貸出タブレットを渡す。持っていないこと自体には触れない |
| 「怖くなってスマホをやめる」と言い出す | **ここが失敗です。** 「使わないほうが不便になります。守り方を知れば大丈夫」と必ずフォロー |
| 主催者が「もっと宣伝していい」と言う | それでも自分からは勧めない。信用が資産です |
