# やさしいAI入門（全4回・90分×4）── 講師用

> 9,800円／90分×4回／オンライン少人数（〜4名）
> 体験を終えた方の受け皿。**継続収入の軸**になるコースです。

---

## 1. 全体設計

### 4回で目指すところ
**受講者が、講座のない日にも自分からAIを開くようになる。**

4回で「教え切る」ことは不可能です。目指すのは網羅ではなく、**習慣の起点**です。

### 回ごとのねらい

| 回 | テーマ | この回で持ち帰るもの |
|----|--------|---------------------|
| 1 | AIと話す・聞き方のコツ | 頼み方の型。うまくいかないのは自分のせいではないと分かる |
| 2 | 調べもの・翻訳 | 検索の代わりに使えるという実感 |
| 3 | 写真と画像 | 家族に見せたくなる成果物が1つ手元に残る |
| 4 | 手紙と文章づくり | 実際に出す手紙が1通できあがる |

**第3回と第4回で「人に見せられるもの」を作る**のが設計の要です。ここで人に話したくなり、紹介が生まれます。

### 4回を通した約束

- 宿題は出さない
- 前回の復習から必ず始める
- 「忘れていて当たり前」を毎回言う
- 録画を毎回渡す
- 4回目に次のコースを勧めない（希望者にだけ案内を渡す）

### 少人数（〜4名）の運営

| 課題 | 対処 |
|------|------|
| 進度の差が出る | 早い方に「◯◯さんに教えてあげてください」と振る。教える側が最も定着します |
| 一人が質問を独占する | 「順番にうかがいますね」と明示的に回す |
| 一人が黙り込む | 名前を呼んで**具体的に**聞く。「いま画面はどこまで出ていますか」 |
| 一人が欠席 | 録画を送り、次回冒頭で3分おさらい |

## 2. 毎回共通の90分の型

| 時間 | 内容 | 目的 |
|------|------|------|
| −10分 | 接続待機 | 遅刻・接続不良を吸収 |
| 0–10 | 前回の復習・近況 | 場をあたためる |
| 10–20 | 今日やることの説明 | 見通しを持たせる |
| 20–50 | 一緒に手を動かす（3つ） | 主要部 |
| 50–60 | 休憩 | ★必ず取る |
| 60–80 | 自分のテーマでやってみる | 個別に見る |
| 80–88 | 質問・持ち帰り確認 | 定着 |
| 88–90 | 次回予告 | 継続 |

**20–50分は「3つの練習」で組みます。** 1つ10分。3つめが終わらなくても構いません。

---

## 3. 第1回：AIと話す・聞き方のコツ

### この回のねらい
**うまくいかないのは、頼み方のせいだと分かること。**「私には向いていない」と思わせないこと。

### 3つの練習

**練習1：あいさつと言い直し（10分）**
- 「はじめまして。やさしい言葉で、短く答えてください」
- 返ってきたら「もっとやさしく」「もっと短く」を試す
- **何度でも言い直させていい相手だ**と体で分かってもらう

**練習2：5つの材料を入れる（10分）**
同じ質問を、材料なし → 材料ありで比べます。

- 材料なし：「旅行のおすすめを教えて」
- 材料あり：「**70代の夫婦で、来月、電車で2時間以内**の温泉に行きたい。**あまり歩かずに回れる**ところを**3つ**教えて」

答えの違いを並べて見せる。ここが第1回の山場です。

> 「同じAIでも、こんなに変わります。**AIが賢いかどうかではなく、こちらの頼み方なんです**」

**練習3：やってほしくないことを言う（10分）**
- 「専門用語は使わないでください」
- 「**推測で補わないでください。分からない部分は分からないと書いてください**」

2つめは全4回を通して繰り返します。

### 60–80分：自分のテーマ
各自の「今日困っていること」を、順番に1人5分ずつ。

### 持ち帰り
紙に「5つの材料」を書いて渡す（誰が／誰に／どんな形で／してほしくないこと／例）

---

## 4. 第2回：調べもの・翻訳

### この回のねらい
**検索の代わりに使えると分かること。** そして**確認の習慣**を同時に付けること。

### 3つの練習

**練習1：話しかけて調べる（10分）**
- 「墨田区で、65歳以上が使える健康診断の制度を教えてください」
- **必ずセットで**：「この内容は、区役所で確認したほうがいいですか」と聞かせる

**練習2：写真を見せて聞く（10分）**
- 手元の書類・薬の袋・家電の説明書を撮って「これは何と書いてありますか」
- カメラの使い方でつまずく方が出ます。時間を多めに

**練習3：翻訳（10分）**
- 英語のメニューやパッケージを撮って日本語に
- 「観光の方に道を聞かれたら」の場面を実演

### 必ず入れる注意
> 「調べものは便利ですが、**お店の名前や営業時間、制度の期限は、AIが平気で間違えます。**
> 大事なことは、必ずご自分で確かめてください。電話1本で済みます」

### 持ち帰り
「AIに聞いていいこと／自分で確かめること」の一覧（紙）

---

## 5. 第3回：写真と画像

### この回のねらい
**家族に見せたくなるものを1つ作る。** この回がいちばん盛り上がります。

### 3つの練習

**練習1：写真を探す・整理する（10分）**
- 「去年の秋に撮った写真」を探す
- 撮りっぱなしの写真から1枚選ぶ

**練習2：絵を作ってもらう（15分）**
- 「秋の墨田区の風景を、水彩画ふうに描いてください」
- 年賀状、暑中見舞い、お孫さんへのカードの題材で
- **できたものを保存する手順まで**必ずやる

**練習3：家族に送る（10分）**
- LINEで送るところまで一緒にやる
- ここまでやらないと家に帰って止まります

### 注意
- 生成した画像を「本物の写真」として使わないこと
- 人の顔写真を勝手に加工しないこと

### 持ち帰り
作った画像そのもの（スマホの中に残る）。**これが最大の成果物です。**

---

## 6. 第4回：手紙と文章づくり

### この回のねらい
**実際に出す手紙を1通、完成させて帰る。**

### 3つの練習

**練習1：気持ちを話す → 形にする（15分）**
- 相手・場面・伝えたいことをAIに話す
- 出てきた文章を読む

**練習2：自分の言葉に直す（15分）**
**これが第4回の核心です。**

> 「このまま出してはいけません。**AIの文章は、上手ですが、あなたの言葉ではありません。**
> 1か所でいいので、ご自分の言い方に直してください。そこが手紙のいちばん大事なところになります」

**練習3：清書して出す（10分）**
- 印刷するか、書き写すか、LINEで送るか
- **出すところまで**を講座内で終える

### 締めくくり（88–90分）

> 「4回、おつかれさまでした。
> 今日から、**分からないことがあったら、まずAIに聞いてみてください。** 何を聞いても怒られません。
> それでも分からなければ、いつでもお電話ください」

**次のコースは勧めません。** 案内の紙を置くだけにします。

### 持ち帰り
- 完成した手紙
- 4回分の録画
- 「困ったときの電話番号」カード

---

## 7. つまずきポイントと対処（全4回共通）

| 症状 | 対処 |
|------|------|
| 進度が開く | 早い方に教え役を振る。遅い方は休憩時間に個別で追いつかせる |
| 「私だけできない」と落ち込む | **その場で全員に向けて**「ここは全員が止まるところです」と言う |
| 前回を完全に忘れている | 想定内。0–10分の復習を厚くする。責める言葉を一切使わない |
| 画面共有が見えない | 音声で「いま画面のどのあたりですか」と確認。文字サイズを上げる |
| 一人だけ回線が切れる | 全体を止めない。電話で個別に復帰させる。録画があると伝えて安心させる |
| 有料版を勧められた（AI側から） | 「無料のままで大丈夫です」と明確に。課金の心配を残さない |
| 4回目に「もっと続けたい」と言われる | 月額コースの紙を渡す。**その場で契約しない。**「持ち帰って考えてください」 |

- [ ] 「自分で確かめること」に触れた
