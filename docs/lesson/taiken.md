# はじめてスマホ＆AI 体験（60分）── 講師用

> 500円／60分／オンライン・出張／マンツーマン〜少人数
> このコースは**入口**です。教えることより、こわくないと分かってもらうことが目的です。

---

## 1. 設計

### 到達目標
**受講者のスマホにChatGPTが入っていて、自分で一度話しかけて答えをもらえた状態**で終わること。

### 最低ライン（時間が足りなくてもこれだけは）
**アプリを入れて、1回話しかけられた。** これができれば、この60分は成功です。
「学んだこと」がゼロでも構いません。手元に道具が残ることが価値です。

### やらないこと
- 使い方を網羅的に教えない
- 有料版の説明をしない
- 次のコースを勧めない（聞かれたら答える程度）
- 専門用語を一つも使わない

### 最大の難所
**アカウント作成です。** 60分のうち、ここに15分を確保しておいてください。
つまずく原因のほぼすべてが「Apple ID / Googleアカウントのパスワードが分からない」です。
**これは前日の電話で潰しておきます**（次項）。

---

## 2. 前日の電話（10分）── ここが勝負

この電話をやるかどうかで、当日の成否が決まります。省略しないでください。

### 確認すること

| # | 聞くこと | なぜ |
|---|---------|------|
| 1 | お使いの機種は iPhone ですか、それ以外ですか | 画面の説明が変わります |
| 2 | App Store（またはPlayストア）で、これまでアプリを入れたことはありますか | 未経験ならさらに時間を見ます |
| 3 | **Apple ID（Googleアカウント）のパスワードは、すぐ出てきますか** | ★最重要。分からない場合は当日までに再設定をお願いする |
| 4 | Wi-Fiにはつながっていますか | 通信量の心配を先に消します |
| 5 | 今日いちばん困っていることを1つ教えてください | 当日30分めに使います |
| 6 | （オンラインの場合）ビデオ通話のつなぎ方を、いま一緒に練習しましょう | 当日の接続不安をここで消す |

### そのまま言える言葉

> 「明日の準備で、1つだけお願いがあります。アプリを入れるときに、iPhoneのパスワードを聞かれることがあるんです。すぐに思い出せそうでしょうか。……もし分からなければ、いま一緒に確認しておきましょう。当日にそこで止まってしまうと、もったいないので」

パスワードが分からない場合は、**当日の前に再設定を済ませてもらう**か、**再設定から一緒にやる前提で15分多く見積もる**かのどちらかです。

### 講師側の準備
- ChatGPTアプリを自分の端末にも入れておく（画面共有用）
- iPhone版・Android版の両方の画面を、あらかじめ手元に用意
- 紙とペン（受講者に手順を書いて渡す）
- （出張）貸出タブレット、モバイル通信、身分証

## 3. 進行表（60分）

| 時間 | 内容 | 目的 |
|------|------|------|
| −15分 | 接続待機／到着・設置 | 遅れを吸収する |
| 0–5 | あいさつ・今日やること・お約束 | 緊張をほどく |
| 5–20 | ChatGPTアプリを入れる | ★最難関 |
| 20–30 | はじめて話しかけてみる | 「できた」の体験 |
| 30–45 | ご自分の困りごとを試す | 自分ごとにする |
| 45–52 | わざと知らないことを聞く | 信じすぎない線引き |
| 52–58 | 明日使う理由をつくる | 続く仕掛け |
| 58–60 | お礼・口コミのお願い | ★忘れない |

**5分の予備を常に持ってください。** 押したときは30–45分のブロックを削ります。

## 4. ブロックごとの進め方

### 0–5分：あいさつとお約束

いきなり本題に入らないこと。まずこの3つを口に出します。

> 「今日は60分ですが、**何かを覚えて帰る必要はありません。** 一度触ってみて、こわくないと分かっていただければ、それで十分です」
>
> 「途中で分からなくなったら、**どこでも止めてください。** 『待って』と言っていただくのが、いちばん助かります」
>
> 「同じことを何度聞いていただいても構いません。**忘れるのは自然なことで、あなたのせいではありません**」

3つめは必ず言ってください。この一言で表情が変わります。

### 5–20分：アプリを入れる（★最難関）

画面を見せながら、**一手ずつ**進めます。先回りしないこと。

1. ホーム画面から **App Store**（青地に白い「A」）／ **Playストア**（カラフルな三角）を開く
2. 下の **検索**（虫めがね）を押す
3. 「**チャットGPT**」と入力（カタカナで出ます）
4. **作った会社が「OpenAI」になっているか**を一緒に確認する ← ここは声に出して確認
5. **入手**／**インストール** を押す
6. パスワードまたは指紋・顔認証
7. 開く → **アカウントを作る**
   - 「Googleで続ける」「Appleで続ける」を**最優先で選ぶ**（新しいパスワードを覚えなくて済む）
8. マイクの許可を聞かれたら **許可**

> 「にせものそっくりのアプリもあるんです。作った会社の名前が『OpenAI』かどうか、ここを毎回見てください。これは今日いちばん大事なことかもしれません」

### 20–30分：はじめて話しかける

**キーボードは使わせません。** 最初は必ずマイクから。

1. 下の入力欄の **マイクのマーク** を押す
2. これを読み上げてもらう ↓

> 「はじめまして。AIは初めてです。やさしい言葉で、短く答えてください」

3. 答えが返ってきたら、**一緒に読む**
4. 続けてもう1回：「もっとやさしく言ってください」

ここで**必ず拍手か声かけ**をします。「できましたね」の一言を惜しまないこと。

### 30–45分：ご自分の困りごと

前日の電話で聞いておいた困りごとを出します。

> 「昨日おっしゃっていた◯◯のこと、いま聞いてみましょうか」

自分の生活の話が返ってくると、態度が変わります。ここが山場です。

うまい題材が出てこないときの逃げ札：
- 「冷蔵庫に◯◯があります。夕飯のおかずは何が作れますか」
- 「明日の墨田区の天気を教えてください。散歩に上着は要りますか」
- 「お孫さんへの誕生日メッセージを一緒に考えてもらいましょうか」

### 45–52分：わざと知らないことを聞く

**このブロックは絶対に飛ばさないでください。** 教室の看板がかかっています。

> 「今度は、わざと意地悪な質問をしてみましょう。AIが知らないはずのことを聞きます」

例：「今日の夕方、東京駅の3番ホームには何人いますか」

答えを一緒に見てから：

> 「AIはこんなふうに、**知らないことでも答えらしいものを作ってしまう**ことがあります。堂々と間違えるんです。
> だから、**お薬のこと、お金のこと、大事な判断は、AIの答えだけで決めないでください。** 必ずお医者さんやご家族に確認を。
> 便利さと同じくらい、これを覚えて帰っていただきたいと思っています」

### 52–58分：明日使う理由をつくる

続くかどうかは、ここで決まります。

1. AI自身に聞かせる：「私が明日もあなたを使うとしたら、どんな場面が考えられますか。いくつか質問してから提案してください」
2. 返ってきた提案の中から、**1つだけ**選んでもらう
3. **紙に書いて渡す**（アプリの開き方＋その1つ）

> 「明日、これだけやってみてください。ひとつで十分です」

### 58–60分：締めと口コミ

**押し売りは一切しません。**

> 「今日はここまでです。続けるかどうかは、決めていただかなくて大丈夫です。体験だけで終わっても、まったく構いません」
>
> 「もし今日の時間がよかったと思っていただけたら、**Googleに一言だけ感想を書いていただけると、とても助かります。** このQRコードから開きます。ひとことで結構です」

QRコードのカードをその場で渡す。**後日メールでは9割書いてもらえません。**

## 5. つまずきポイントと対処

| 症状 | 原因 | その場での対処 |
|------|------|--------------|
| App Storeで「入手」を押しても進まない | Apple IDのパスワード／支払い情報未設定 | 前日電話で潰す。当日なら再設定に切り替え、時間を延長する |
| 検索しても出てこない | 「ちゃっとGPT」等の入力ゆれ | 講師が読み上げて一文字ずつ。カタカナ「チャットGPT」で出ます |
| 似たアプリが並んで分からない | 偽アプリ | 「OpenAI」の文字を一緒に指さす。この確認自体を教材にする |
| 認証メールが届かない | 迷惑メールフォルダ | 迷惑メールを一緒に確認。または Google/Apple 連携に切り替える |
| SMS認証の番号が読めない | 通知バナーが消える | メッセージアプリを開いて確認する手順を見せる |
| マイクが反応しない | 権限が「許可しない」 | 設定 → ChatGPT → マイク を一緒に開く |
| 声を拾わない | 小声・方言・早口 | 「少し大きめに、ゆっくり」。だめならキーボードに切替え、講師が代打ちする |
| 画面が小さくて読めない | 文字サイズ設定 | **その場で文字を大きくする。** これ自体が喜ばれます |
| （オンライン）つながらない | 接続不安 | すぐ電話に切り替える。電話越しでも60分は成立します |
| 途中で黙ってしまう | 分からないが言い出せない | 「いま、どのあたりで止まっていますか」と**こちらから聞く** |
