# お問い合わせフォームの本番化手順（Googleフォーム連携）

サイトのフォームは、**Googleフォームに送信される本物のフォーム**として動かせます。
費用は無料。設定は `assets/config.js` にURLを2種類貼るだけです。

---

## 手順1: Googleフォームを作る（約10分）

1. https://docs.google.com/forms で新しいフォームを作成
2. タイトル例:「すみだAIきょうしつ お申し込み」
3. **質問を6つ、この順番で**作ります（種類はすべて「記述式」でOK）:

| # | 質問タイトル | 対応するサイトの項目 |
|---|---|---|
| 1 | どなたのお申し込みですか | who |
| 2 | お名前 | name |
| 3 | お電話番号 | tel |
| 4 | ご希望のコース | course |
| 5 | ご希望の受け方 | mode |
| 6 | ご相談内容 | msg |

4. 右上の歯車（設定）→「回答」→ **メール通知をオン**にすると、申し込みが来るたびメールが届きます。

## 手順2: 送信先URL（formResponse）を調べる

1. フォーム右上の「送信」→ リンクのマークでURLをコピー
   例: `https://docs.google.com/forms/d/e/1FAIpQLSe○○○/viewform`
2. 末尾の `viewform` を **`formResponse`** に置き換えたものが送信先URLです:
   `https://docs.google.com/forms/d/e/1FAIpQLSe○○○/formResponse`

## 手順3: 各質問の entry ID を調べる

1. フォームの「プレビュー」（目のマーク）を開く
2. ページの何もないところを右クリック →「ページのソースを表示」
3. `Ctrl+F`（Macは`Cmd+F`）で **`entry.`** を検索
4. `entry.123456789` のような番号が質問の数だけ見つかります。
   **上から順に、質問1〜6に対応**しています（`[["entry.123456789", ...]]` という形の場所を見ます）。

> うまく見つからない場合: プレビューで各項目に適当な文字を入れ、送信直前にブラウザの開発者ツール（F12）→「ネットワーク」タブで `formResponse` への送信内容を見ると、`entry.○○=入力値` の形で確実に確認できます。

## 手順4: assets/config.js に貼り付ける

```js
GOOGLE_FORM_ACTION: "https://docs.google.com/forms/d/e/1FAIpQLSe○○○/formResponse",
GOOGLE_FORM_ENTRIES: {
  who:    "entry.111111111",
  name:   "entry.222222222",
  tel:    "entry.333333333",
  course: "entry.444444444",
  mode:   "entry.555555555",
  msg:    "entry.666666666"
},
```

保存してmainにpushすれば反映されます。設定後は自動的に:
- 「デモ用フォームです」の注意書きが消える
- 送信内容がGoogleフォームの回答（スプレッドシート連携可）に届く

## 動作確認

サイトのお問い合わせページから試しに送信 → Googleフォームの「回答」タブに届いていればOK。

> 補足: この方式（no-cors送信）はGoogleの仕様上「送信成功」の確認が取れないため、電話番号の記載と併用するのがおすすめです。申込が増えてきたら、Formspree や独自のフォームサービスへの移行もご相談ください。
